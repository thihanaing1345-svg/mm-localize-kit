# Changelog

All notable changes to **mm-localize-kit** will be documented in this file. This project follows the spirit of semantic versioning while the public API is still stabilizing during early releases.

## [0.1.0] - 2026-06-04

### Added

- Initial TypeScript package structure for Myanmar localization helpers.
- Unicode-oriented Myanmar text detection and normalization utilities.
- Myanmar phone number normalization, validation, parsing, and operator-prefix helper functions.
- MMK currency formatter with optional Myanmar numerals.
- Burmese numeral conversion utilities.
- Myanmar-facing date formatter.
- Starter township and region helper dataset with documented provenance policy.
- Search normalization helper for mixed Myanmar and English text.
- React and Next.js-friendly form validation helper functions.
- CLI entry point for cleaning Myanmar text datasets.
- Unit tests for all MVP utility areas.
- Examples for React, Next.js, plain JavaScript, browser demo usage, Node.js, and CLI workflows.
- Open-source community files, including contributing guide, code of conduct, security policy, issue templates, and pull request template.

### Notes

- This is an honest early release. It does not claim existing production adoption, npm download volume, or community size.
- Unicode/Zawgyi detection is heuristic in v0.1.0 and should be improved with reviewed real-world samples.
