# Data Provenance

The MVP includes a small synthetic starter dataset for demonstration and tests. Before expanding the township, region, telecom, or language datasets, contributors must document the source, license, redistribution permission, transformation process, and review date.

| Dataset | Current status | Provenance requirement |
| --- | --- | --- |
| Township helper data | Starter sample only | Replace or expand only with license-compatible public data and source notes. |
| Phone/operator rules | Heuristic rules | Validate with public telecom numbering references and community review. |
| Zawgyi/Unicode fixtures | Minimal examples | Add labeled fixtures with source and permission. |
