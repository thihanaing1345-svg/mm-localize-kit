# Public Launch Plan

## Launch channels

| Channel | Action | Tone |
| --- | --- | --- |
| GitHub | Publish repository, add topics, create first release, and pin roadmap issues. | Technical and transparent. |
| Facebook developer groups | Share a concise post asking for feedback from Myanmar web developers. | Community-first, not promotional spam. |
| LinkedIn | Explain the developer problem and invite maintainers, educators, and startup engineers to test it. | Professional and ecosystem-focused. |
| Myanmar tech communities | Ask for validation of phone, township, Unicode, and search assumptions. | Humble and collaborative. |
| Personal portfolio | Add a case-study page describing the project mission, roadmap, and contribution needs. | Credibility-building. |
| Documentation site | Launch a small docs site after the API stabilizes. | Practical and example-driven. |

## Sample launch message

I launched `mm-localize-kit`, an open-source TypeScript toolkit for Myanmar-language websites and apps. It includes utilities for Unicode cleanup, Myanmar phone validation, MMK formatting, Burmese numerals, date formatting, township helpers, search normalization, React/Next.js validators, and a CLI for cleaning text datasets. The project is new, so I am looking for real feedback, edge cases, and contributors rather than claiming it is production-proven. Repository: https://github.com/thihanaing1345-svg/mm-localize-kit
